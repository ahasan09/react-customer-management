# React App

React 18 + Vite application for customer management with client-side routing (React Router v5) and Bootstrap styling.

## Tech Stack
- React 18
- Vite
- React Router v5 (Switch/Route API)
- Bootstrap 4
- Vitest + React Testing Library
- JavaScript (ES6+)

## Project Structure
```
react-app/
├── index.html          # Vite entry HTML
├── vite.config.js
├── src/
│   ├── main.jsx        # Entry point (createRoot)
│   ├── App.jsx         # Routes
│   └── components/
├── public/
└── package.json
```

## Development
```bash
# Install dependencies
npm install

# Run development server (port 3000)
npm run dev

# Run tests
npm test

# Build for production (outputs to build/)
npm run build
```
